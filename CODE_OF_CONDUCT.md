# Code of Conduct

AbstractFlow follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

## Our standards

Be respectful, constructive and inclusive in issues, pull requests, discussions and any other
project space. Harassment, personal attacks, discriminatory language and publishing others'
private information are not acceptable.

## Reporting

Report unacceptable behavior privately to the maintainer through GitHub
([@lpalbou](https://github.com/lpalbou)). Reports are handled confidentially. For security
vulnerabilities, follow [`SECURITY.md`](./SECURITY.md) instead.

## Enforcement

The maintainer may remove, edit or reject contributions that do not follow this code of conduct,
and may temporarily or permanently restrict participation in project spaces.
